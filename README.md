# Nexo

### Un catálogo central. Contenido de producto para múltiples tiendas.

Nexo es un proyecto en desarrollo para administrar experiencias de producto 3D y realidad aumentada desde un catálogo central y distribuirlas a sitios de comercio electrónico.

Este repositorio es una **presentación pública**, no el código fuente del sistema. La implementación se mantiene en un repositorio privado.

## La idea

Crear cada producto una sola vez, identificarlo por marca y código y reutilizar su contenido en distintas tiendas. El propietario administra el catálogo y decide qué se publica y dónde se muestra.

## Lo que ya existe

- Prototipo navegable del panel de administración.
- Catálogo de productos y marcas con editor y vista previa.
- Demostración local de borradores, publicaciones, historial y asignación de productos a tiendas.
- Visores independientes de producto con rotación, colores y controles interactivos.
- Experiencias AR preparadas para iPhone y Android compatibles; la disponibilidad depende del dispositivo.
- Integración de los visores mediante iframe.

**Estado actual:** el panel es un prototipo. Sus datos se guardan en el navegador y sus acciones de publicación son simuladas. No es todavía un servicio de administración en producción.

## Próximas etapas

- Persistencia central de productos y configuraciones.
- Autenticación del administrador.
- Publicación real con separación entre borrador y versión publicada.
- Resolución automática de productos por marca y código.
- Configuración de distribución por tienda.

Estas capacidades describen la dirección del proyecto, no funciones actualmente disponibles.

## Qué contiene este repositorio

Solo documentación de presentación. No incluye el panel ejecutable, código del servidor, modelos 3D, credenciales, información de clientes ni bases de datos.

No hay una demo ejecutable ni una instalación del sistema disponible desde este repositorio.
